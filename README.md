# Compiler_Lab-xjtu

2026 编译器实验网页整合项目。

## 项目说明

本项目将实验功能拆为：

- 前端：`index.html`（导航页 + 各实验页面，负责输入输出展示）
- 后端：`server.py` + `backend/`（负责算法与逻辑计算）

当前包含：

- 实验1：DFA（文法转 DFA、DFA 文本加载、字符串判定、语言枚举、最小化）
- 实验2：词法分析（默认词法 DFA）
- 实验3：LR(0) 判定（输入 grammar，输出分析结果并支持状态图渲染）

## 面向用户功能介绍

这个网页适合直接作为课程实验展示与演示入口：

- 进入首页后，可以看到实验1、实验2、实验3三个入口
- 每个实验都提供输入区和输出区，操作步骤清晰，适合课堂演示
- 所有核心计算都在后端完成，前端只负责交互和结果展示
- 可直接用于展示“输入 -> 分析 -> 输出结果”的完整流程

具体体验上：

- 实验1可以把文法或 DFA 文本转换为可视化结果，并做判定、枚举和最小化
- 实验2可直接对代码做词法分析，生成 token 流和错误信息
- 实验3可输入文法后直接得到 LR(0) 判定文本，并可查看状态图

## 环境要求

- Python 3.10+（建议 3.11+）
- Windows / macOS / Linux 均可

## 安装依赖

在项目根目录执行：

```bash
python -m pip install -r requirements.txt
```

## 启动方式

```bash
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

启动后访问：

- <http://127.0.0.1:8000/>

## 使用说明

### 导航页

首页列出三个实验，点击进入对应实验页面。

### 实验1（DFA）

- 输入文法或 DFA 文本
- 生成/加载 DFA 后可查看：
  - 五元组
  - DFA 文本
  - DOT 描述
  - 状态图
- 可执行：
  - 字符串判定
  - 接受串枚举
  - DFA 最小化

### 实验2（词法分析）

- 输入源码（支持文件读取）
- 使用默认词法 DFA
- 输出：
  - Token 流
  - 词法错误

### 实验3（LR(0)）

- 输入 grammar（支持两种格式）：
  - 第一行是产生式数量 N，后面 N 行产生式
  - 或直接每行一条产生式
- 输出：
  - LR(0) 判定完整文本
  - DOT 状态图描述
  - 状态图渲染

## 常见问题

- **端口占用（WinError 10048）**
  - 原因：`127.0.0.1:8000` 已被占用（通常是已有服务正在运行）
  - 处理方案：
    1. 直接使用现有服务：访问 `http://127.0.0.1:8000/`
    2. 或结束旧进程后重启：
       - `taskkill /PID <pid> /F`
    3. 或改端口启动：
       - `python -m uvicorn server:app --host 127.0.0.1 --port 8001`
